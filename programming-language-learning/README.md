# 🎓 CodeLingo - 프로그래밍 언어 학습 웹앱

듀오링고 스타일의 프로그래밍 언어 학습 플랫폼 프로토타입입니다.

## 🚀 주요 기능

- **언어 선택**: JavaScript, Python, TypeScript, React 등 다양한 프로그래밍 언어
- **대화형 퀴즈**: 객관식, 빈칸 채우기, 코드 완성 문제
- **진행도 추적**: 경험치(XP), 연속 학습일, 완료한 레슨 수 추적
- **반응형 디자인**: 모바일과 데스크톱 모두 지원
- **로컬 저장소**: 브라우저에 학습 진행도 자동 저장

## 🛠 기술 스택

- **Frontend**: React 18 + TypeScript
- **스타일링**: Tailwind CSS
- **상태 관리**: React Hooks
- **데이터 저장**: LocalStorage
