# IoT Health Care - 프로젝트 진행 상황

## 📋 프로젝트 개요
IoT 기기(주로 공유기)의 보안 상태를 진단하고 개선 방안을 제시하는 웹 애플리케이션

## 🏗️ 아키텍처
- **Frontend**: React + TypeScript + Tailwind CSS
- **Backend**: Node.js + Express + TypeScript
- **포트**: Frontend(3000), Backend(3001)

### B. 기본 모드 개선
- **관리자 비밀번호 점수**: 0으로 설정 (알 수 없음)
- **권장사항**: 관리자 관련 내용 제거, "정밀 진단 권장" 메시지 추가

### C. 점수 산정 로직 개선
```typescript
// 감점 방식으로 변경 (100점에서 시작)
let score = 100;
if (checks.passwordStrength.wifi < 70) score -= deduction;
if (checks.openPorts.length > 3) score -= (length - 3) * 4;
if (!checks.firmwareUpdate) score -= 15;
if (checks.wpsEnabled) score -= 12;
if (checks.remoteManagement) score -= 10;
```

## 🚨 현재 해결 중인 문제

**증상**: 프론트엔드에서 400 Bad Request 오류 발생
**원인**: 이전 컨트롤러 코드가 여전히 실행 중
**해결 시도**:
- 컨트롤러 오류 메시지 수정 완료
- 백엔드 재빌드 및 재시작 완료
- 타입 정의 수정 (`defaultCredentials: boolean | null`)

**다음 단계**: 서버 프로세스 완전 종료 후 재시작 필요

```bash

cd backend && npm run dev

# 프론트엔드 시작  
cd frontend && npm start
```
