# 🏥 IoT Health Care - IoT 기기 보안 진단 서비스

## 📋 프로젝트 개요
IoT Health Care는 가정용 IoT 기기(특히 공유기)의 보안 상태를 병원의 건강 진단처럼 체크리스트 형태로 점검해주는 웹 서비스입니다. 

## 🎯 프로젝트 목적
- IoT 기기의 보안 취약점을 쉽고 직관적으로 진단
- 사용자 친화적인 인터페이스로 보안 관리의 접근성 향상
- 정기적인 보안 점검을 통한 예방적 보안 관리

## 🏥 컨셉
**"IoT 기기 건강 진단소"**
- 병원의 건강 검진처럼 친근하고 신뢰할 수 있는 이미지
- 진단서, 처방전 형태의 결과 제공
- 정기 검진 알림 기능

## 🔧 주요 기능

### 1단계: 공유기 보안 진단
- **기기 정보 수집**: 모델명, 펌웨어 버전, 설정 정보
- **펌웨어 업데이트 체크**: 최신 버전 확인 및 업데이트 알림
- **비밀번호 강도 검사**: 관리자 계정, WiFi 비밀번호 보안 수준 평가
- **포트 스캔**: 불필요한 열린 포트 검사
- **기본 설정 점검**: WPS, 원격 관리 등 보안 설정 확인

### 추가 제안 기능
- **네트워크 트래픽 분석**: 의심스러운 통신 패턴 감지
- **연결 기기 모니터링**: 알 수 없는 기기 접속 감지
- **보안 인증서 검증**: SSL/TLS 인증서 유효성 확인
- **DNS 설정 검사**: 악성 DNS 서버 사용 여부 확인
- **UPnP 보안 점검**: UPnP 설정의 보안 위험도 평가

## 🛠 기술 스택 (예정)
- **Frontend**: React.js + TypeScript
- **Backend**: Node.js + Express
- **Database**: MongoDB
- **보안 스캔**: Nmap, OpenVAS 등
- **배포**: AWS (EC2, RDS, S3)

## 📊 진단 결과 형태
- **종합 건강도**: A~F 등급
- **위험도별 분류**: 긴급, 주의, 양호
- **개선 권장사항**: 구체적인 해결 방법 제시
- **정기 검진 일정**: 다음 점검 권장 시기

## 🚀 개발 로드맵
1. **1단계**: 공유기 기본 보안 진단 기능
2. **2단계**: 다양한 IoT 기기 지원 확장
3. **3단계**: AI 기반 위협 탐지
4. **4단계**: 모바일 앱 개발
